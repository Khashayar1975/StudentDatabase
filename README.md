# Entity Framework Core Code-First Student Database

## Project Description
This C# Console Application demonstrates the Entity Framework
Core Code-First approach using .NET 10.

## Technologies
- C#
- .NET 10
- Entity Framework Core 10
- SQLite

## Features
- Automatically creates a Student database.
- Creates a Students table using Code-First.
- Adds a student record.
- Saves the student to the database.
- Displays student information.
- Prevents duplicate student insertion.
